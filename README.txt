MYWARE - Warehousing & Logistics Marketplace

1. HOW TO RUN (DIRECT):
   No terminal or Python server is needed.
   Just double-click "index.html" and open it in any browser (Chrome, Edge, Firefox).
   The website runs completely on its own.

2. DEMO SHORTCUTS (to test every role):
   Use the demo links on the Login page to fill in credentials quickly:
   - Admin:  admin@local / admin123
   - Seller: seller@local / seller123
   - Buyer:  buyer@local / buyer123
   - Public guest: visitor home page and quote requests

3. REGISTRATION:
   Registration is available for sellers only. New seller accounts
   become active after admin approval. Buyers do not need to register;
   they can request a quote directly from the home page.

4. DATA PERSISTENCE:
   Any service you add, quote you send, order you place or status you
   update is saved automatically in your browser.

5. BACKEND SERVER (NODE.JS):
   To run with the backend server:
   - Run `node server.js` or `npm start`
   - Visit http://localhost:8000
